# Scoping call

> [!info] Processo/PMO

Sessão que **antecede as janelas de certificação** e serve para acordar o alcance — **não** para executar provas.

## O que se fecha nela
- **Quais casos do script aplicam** e quais são marcados como *no aplica*, com base no perfil do cliente.
- **Verificação dos insumos:** estação de teste ativa (confirmada por *ecotest*), dados do cartão a tokenizar compartilhados com o certificador.
- **Necessidade de participação de terceiros** ([[Processador|processador]], [[ITSP]]) durante as janelas.
- **Agendamento das janelas** de prova.

Ao final, o engenheiro envia o convite **com o script anexo**, incluindo os casos marcados como não aplicáveis — o banco deve avisar se discordar de alguma marcação.

> [!tip] O que essa sessão pode resolver de graça
> Casos que o banco não consegue executar às vezes simplesmente **não se aplicam** ao seu perfil. No [[BROU — dossiê|BROU]], o caso **13.2 (Dynamic CVV)** era a única prova pendente e foi encerrado como *no aplica* — sem nenhuma execução. Revisar o script antes evita o banco travar achando que tem caso pendente. O mesmo costuma valer para [[OCT - AFT|AFT e OCT]] em emissores que não participam desses fluxos.
