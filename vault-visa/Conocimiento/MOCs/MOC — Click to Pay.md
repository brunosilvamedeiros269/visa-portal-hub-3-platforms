# MOC — Click to Pay

Términos del glosario en esta categoría.

- [[Click to Pay]] — Mandato Visa para pagar sem digitar o cartão. Fase 1: enrolamento massivo (tem TPM). Fase 2: ciclo de vida (sem TPM). Fase 3: logo.
- [[Destination Site]] — Site legado onde o consumidor se enrolava sozinho; fica somente-leitura quando o emissor assume a gestão.
- [[Enrolamento massivo]] — Despejar todas as credenciais Visa já emitidas no Click to Pay via processador/tokenizador.
- [[External Consumer ID]] — Identificador do consumidor gerado pelo emissor para o enrolamento massivo.
- [[Passkey - App-to-App]] — Métodos de autenticação de baixa fricção no checkout (biométrico; ou handoff ao app do emissor).
- [[Register Consumer]] — API que registra o consumidor (SRC Profile) no enrolamento; ponto de falha conhecido (HTTP 500) na integração via ITSP.
- [[SRC - EMVCo]] — Secure Remote Commerce (EMVCo, 2019), base do Click to Pay; o ícone é marca da EMVCo.
